# pascals-triangle
This Python program allows for easy visualization of Pascal's triangle in modular systems.

## Usage
Edit the two variables at the top of the files (ROWS and MOD) to modify the appropriate parameter for triangle generation.

To run the program, install the python interpreter. Alternatively, you can use an online site (onecompiler.com is one that I know of that isn't blocked for students).

However, for computationally intensive analysis/larger triangles it may be more efficient to run it locally and print the text to a file.
